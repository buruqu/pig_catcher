# 雾蓝键盘大福增强 · 2.0.26

## 本轮规则

每份仍提供10次专属抓猪。每次独立随机换位六档基础概率后，将目标4/5/6星档位的权重乘5，
最后将所有权重归一化为100%。不是直接给三个星级的最终百分比各乘5，也不是在换位前放大。

例如换位结果为 `30/17/8/4/1/40`，加权后为 `30/17/8/20/5/200`，最终约为
`10.714% / 6.071% / 2.857% / 7.143% / 1.786% / 71.429%`。
抓猪结果的概率栏展示最终实际分布；倍率前的换位比例明确标注为原始比例。

不叠加等级、饲料、永久美食、普通道具、其他个人或全群概率效果；忽略的临时效果不消耗。
正常额度不扣，冷却与监管规则保留；无六星授权时仍将六星份额转移至五星。

四个既有作用域共用同一计算规则，数据仍隔离。已生效且未用完的雾蓝直接适用增强，
不改剩余次数、不补发美食、不重写历史回执。旧背包美食继续通过同一效果协议获得新版说明。
无需数据库迁移；Schema65、Ruleset65、Battle v15。
