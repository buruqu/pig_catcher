## 1. 本轮交付

- `/抓猪帮助` 改为主要入口和专题目录，默认不刷出术式、对战、奖励等全部命令。
- `/抓猪帮助 功能名` 展开一个专题，每页附必要规则、相关专题和返回入口。
- `全部`、`目录`、`首页`、空白输入都回精简目录，未知主题不触发全量展开。
- 保留仓库→背包、图鉴→背包、经济→商城等旧主题别名；既有业务命令不删除、不重命名。
- 派遣、巡演、战斗原有完整帮助继续可用；巡演缩略命令补齐前缀，可从详细帮助返回新目录。
- 纯文字帮助不经过图片渲染，不读取玩家库存、不产生奖励、不改变玩法状态；成功业务结果继续优先图片。

默认配置下主菜单261字符，最长专题为商城1111字符；主菜单/未知主题的测试预算600字符，
单专题预算2000字符。商城全文来自16件商品定义，不通过删减价格或截断有效指令来压缩。


## 3. 真实配置与安全边界

入口先沿用插件总开关、群/用户访问控制、运营限制和帮助开关；通过后才生成内容。
专题中的命令和带操作性的说明依据真实门禁过滤，而不是只在目录隐藏名字。

| 分类 | 开关关系 |
| --- | --- |
| 抓猪、玩家重置额度、立绘切换 | `catching_enabled` |
| 猪猪背包/详情、猪和菜的收藏命令 | `inventory_enabled` |
| 猪/菜图鉴、美食背包/详情 | 各自独立开关 |
| 做菜与四个日常群术式 | `cooking_enabled` |
| 吃菜、确认、轮盘 | `eating_enabled` |
| 装备/取消普通道具 | `items_enabled` |
| 商城/购买/升级、售卖、账本 | 各自开关 |
| 批量保留 | 做菜或售卖任一开启 |
| 赠送、交易 | `trading`内两个独立开关 |
| 成就统计/宝箱/毕业纪念猪 | `achievements_enabled` |
| 佩戴/取消外观 | 成就或周榜任一开启 |
| 道具背包、已有奖励、旧券、改号、自选券 | 不依赖成就统计或普通道具开关 |
| 派遣、巡演、对战、周榜 | 各自开关 |
| 战利品抓猪 | 对战与抓猪同时开启 |

价格只取`ITEM_DEFINITIONS`及当前升级配置；抓猪刷新点、时区、额度、抓猪/做菜冷却、
交易有效期/金额上限从传入的真实设置取值，不做跨群或跨配置缓存。
`format_help(topic, settings=...)`为只读纯函数，无参数时使用新的默认配置对象，不修改调用方设置。

玩家帮助不展示管理员`/重置`或`/猪管…`，也不展示旧档案入口和详情别名。
玩家的`/重置额度`仍公开，但明确先获得资格、真正执行后才给全群收益。
未解锁成就的准确条件、未公开原料交互彩蛋均不新增到帮助中；天逆鉾公开摘要仍只有“解除术式”。
未知专题最多回显32个可打印字符，并替换@、CQ括号及尖括号，不能反射通知标记或无限刷屏。

## 4. 本轮纠正的易错说明

- 图鉴筛选必须写`品质=未收集`，不是把“未收集”单独当参数。
- 排序采用实际枚举：猪为获得时间/品质/价值/体型/重量/名称；菜把体型/重量换成份量。
- 批量默认一至三星，明确品质可选一至五星；六星不纳入批量。保留开关无参数，统一作用于猪和菜。
- 同名道具安排时不预扣库存，重新安排替换同槽队列；取消只清空安排，不再返还不存在的预扣库存。
- 新玩法券每次只选一张，触发后不续用下一张；停用必须提供券名。巡演档期券即时补档期是明确例外。
- 吃菜、材料兑换、猪猪自选、派遣、巡演和战斗各自使用本命令空间的确认，不能互相代办。
- 雾蓝为十次额外抓猪、每次重新随机换位基础概率；不随窗口结束清空，不叠加等级、饲料、云冻或临时效果。
- 六星做菜加成在待用时阻止批量做菜；六星抓猪加成不因此阻止批量做菜。
- 普通六星做菜临时层上限50%，云冻永久层另算；当前10+10+15+5的组合为40%，满层云冻再加10点。
- 佩戴只更新该成就提供的外观部位，未提供的部位保留；没有把三格徽章展示架描述成已可用。

批量做菜的旧docstring和无候选提示一并修正；经济算法未改。
唯一与业务路由相关的小修复是保千切换编号：正则从匿名捕获改成处理器读取的`arguments`命名捕获。
原先直接调用处理器可用、真实群路由却丢号的差异现已由注册路由回归覆盖。
