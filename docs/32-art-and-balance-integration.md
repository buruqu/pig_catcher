# PiG Dream! 2.0 · 全量美术与数值接入

> 2026-08-28 · 第三阶段，隔离开发；不是上线或公告。
> 用户在美术样张和数值方案交付后明确要求「进行下一步，全量制作与接入」。

## 本轮实施边界

- 在 `develop/2.0` 独立工作树制作正式外观包并接入真实功能卡，按第31号确认稿推荐的 N1–N8 落地。
- 新版为 `2.0.0.dev10 / Schema45 / Ruleset39 / AssetManifest4`。正式 1.x 插件、数据库、两个 Bot 与进程不参与。
- 价格候选作为本轮实现基线，包括超级主厨香料2600；只增强悬赏牌与普通香料的未使用库存效果，不虚构逐件购买版本。
- 普通香料采用18点逐档预算；同族四五星菜的提档算法未单独确认，保持原行为。轮盘第3格和首期开放资源价值榜保持已说明的规则。
- 不改猪价、已确认物理资料、六星奖励和互斥规则、派遣/巡演/对战成本。旧资产价值、属性、编号、历史回执及已排队菜品效果不追溯重算，不自动补升级价差。
- 所有四个群作用域使用同一内容版本，玩家数据依旧隔离。
- 帮助分类重构为下一阶段；最终全量回归、生产克隆迁移及维护上线验收再后一阶段。本轮仍做必要的聚焦测试和实际渲染检查，不用样张代替运行接入。

## 功能图片接入

- 抓猪、做菜、详情、个人档案和两类背包/图鉴展示真实已佩戴外观；榜单按真实玩家键读取外观，
  不用昵称匹配。已获得周榜牌不会再因普通成就目录里没有它而丢失显示。
- 抓猪/做菜图片的合成槽配置仍为`38,164,480,480`，没有随长文和外观排版移动。
  DOM保留既有根边框的1px偏差，不宣称截图内容框与合成槽逐像素一致。正文自然增高，
  最终概率优先，长效果、剩余次数、未参与来源分区，不剪裁文字以迁就固定高度。
- 派遣五条路线与材料/器具/纪念品、巡演五类舞台与乐器/角色方向、对战招式/伤势轮盘，
  都使用可复用的主题图形；图上的抽签结果来自已提交回执，不进行第二次随机。
- 道具背包和外观陈列室有独立模板，不再残留派遣出发/归航文案。
- 商城16件道具与两类永久升级都有图标，商品/效果/价格优先展示。
- 群事件区分取得资格、已发动和本次结算；茈展示实际五只猪，御厨子展示两道成品及各自归属，
  轮盘展示真实停靠面，全家桶展示实际人数与合计金额。动画资产在组合清单里标为缩略预览。
- 9条玩家成功出口补齐图片：两种立绘切换、开启/关闭批量保留、收藏保护、佩戴/卸下成就、
  旧成就券和宝箱。设置反馈不重做业务；已有持久回执继续使用原领取与发送幂等。
- 卸下外观仅清除佩戴，不因“周榜开、成就关”的配置而偷偷触发成就历史补录。
- 隐藏未解锁奖励在加载美术前就遮蔽；图片不带内部玩家ID或隐藏触发条件。
- 7类旧页面新增状态图标；收藏、占用、巨物/迷你、双顶、隐私、未发现和缺图各有明确图形。
  纪录与今日巨物按当前群真实玩家键一次批查称号，保留历史原抓取者，不因赠送而改算接收者。

对83个`@Command`路由逐项核查：**70个玩家入口的主要成功路径接图片，11个管理入口和2个帮助
入口保留文字**。取消确认、错误、权限拒绝及图片故障兜底仍可为文字，不能宣称所有分支都是图。
完整证据见[指令出口审查](design/phase3/command-render-audit.md)和[功能卡实现](design/phase3/feature-rendering.md)。
旧页图标、只读投影与同名/跨群隔离见[旧页面收尾记录](design/phase3/legacy-status-icons-and-record-titles.md)。

## 数值落地

- 新菜六档基础价：`14 / 42 / 120 / 420 / 1800 / 25000`。
- 饲料五级价：`300 / 800 / 1800 / 4000 / 8000`；厨具：`300 / 700 / 1600 / 3500 / 7000`。
- 超级主厨香料2600，六星做菜仍+10个百分点；全部16件最终价格见[数值实施表](design/phase3/economy-implementation.md)。
- 悬赏牌猪币奖励×3、经验×1.5。普通香料总预算18个百分点，按操作前分布从低档向相邻高档搬移，
  每份概率只搬一次，不能引入不可达品质；相似普通菜品没有随之暗改。
- 猪趴柠檬茶新实例为一次体型偏移−0.50；猪芙蕾继续两次−0.35。Schema45只更新符合旧默认值的模板，
  不改既有菜实例或已排队效果。旧菜出售仍按其保存价值；旧猪做成新菜按新结算生成。
- 既有库存的悬赏牌/普通香料统一用增强后的效果，因为库存没有逐件购买版本；数量不变。
  历史回执、历史消费、老猪老菜的属性/价值/编号都不追溯改写。
