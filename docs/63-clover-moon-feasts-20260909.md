# 2.0.32 粉蓝冰糕与月栖卷

规则版本：Schema70 / Ruleset71 / Battle17 / Manifest4。四个既有群作用域使用相同规则，玩家状态仍各群隔离。

## 用户确认的规则

粉蓝四叶草冰糕给予10次专属额外抓猪，每次六星概率在纯基础上增加3.07个百分点；当前基础1%，实际为4.07%。这些次数不叠加其他菜品、商城道具、等级、饲料、永久提升或临时成就券，也不消耗被排除的资源。冷却和违规限额继续生效。

统计全部10次原始抓猪的星级总和，复制品不计。先完成全部10次，才生成一次六星猪做菜加成；六星菜概率为10%基础+3.07个百分点+星级总和。最低23.07%，最高73.07%。该次六星猪做菜优先使用这份加成，其他加成保留；无论成功失败都消耗。普通1至5星猪做菜不使用它，也不能产出六星菜。

成功做出六星菜后，事务内发放3次同样六星概率+3.07个百分点的专属额外抓猪，以及7道随机非六星菜。菜品从当前群启用的普通1至5星模板中等概率抽取，可重复；原料专属菜不进入奖励池。奖励不额外触发做菜经验、猪币、周榜或二次奖励。3次奖励抓猪不会再累计做菜概率。

粉蓝有限次数跨时段与重启保留；一次流程未完成时不再吃第二份。不会继续触发旧版“做菜抬抓猪概率、抓六星送7道三星菜”的双向循环。

月栖萤光卷：食用当下的时段正常；下一时段禁止普通、其他专属和战利品抓猪；再下一时段获得15次额外抓猪。这15次优先于其他个人/群六星效果，4/5/6星最终概率各乘3，从低星池等比例扣除；高星合计上限100%，超过时保持高星相对比例。无其他加成时为4星24%、5星12%、6星3%。

月栖15次可与商城道具及非六星菜叠加，同类普通菜仍沿用原互斥/FIFO规则，实际参与才消耗。排除等级、饲料、永久菜品提升、其他六星菜和成就券。每次消耗0普通额度，常规额度不会搬移或扣除；用完15次后同一时段继续按其他原有规则抓猪。未使用机会在奖励时段结束后失效。

用户确认：商城8.8折在**获得15次机会的奖励时段**生效；即使15次已用完，折扣也持续到时段结束。涵盖主商城抓猪/做菜道具及派遣、巡演、对战器具；永久升级维持原价。单价先按原价×88%向上取整为整数猪币，再乘购买数量。展示、扣款、功能道具数量账本记录同一成交价，其他玩家不享受此人的折扣。

## 升级与恢复

Schema70只增加两张新状态表和索引；未食用的旧粉蓝冰糕/月栖卷（含收藏和交易锁定实例）更新效果ID及固定参数。已经吃下的旧时段效果、历史回执、资产编号、所有权、余额和账本不重写；旧效果自然结束后再食用新版本。同一来源、十次计数、做菜消耗和奖励发放均处于原命令事务及消息幂等边界。

档案卡显示累计星级、剩余次数、做菜概率、禁抓/奖励时段与折扣。食用、抓猪、做菜和商城沿用正式图片样式及持久化文字回执。

## 验证与发布

开发验证覆盖成功与失败分支、全10次统计、73.07%上界、普通猪边界、次数耗尽、跨时段/重启/重复消息、道具与普通菜的消耗与保留、战利品禁抓、全部商城种类、折扣边界与其他玩家隔离、奖励池缺失整笔回滚。

正式发布前使用在线一致性副本演练迁移与恢复，检查完整性、外键、账本和逐表数据差异；验证正式四群素材语义与浏览器实际渲染。发布复用既有非删档流程，备份后替换受管代码与目录，保留私人配置。测试数据仅在隔离库中创建，不向QQ发送验收消息。

验证结果：完整回归2218项通过；最后概率来源显示修正后，抓猪/渲染/新菜71项针对性复核通过。正式库副本迁移8份未食用菜品，其他业务表内容未变，备份恢复摘要一致；10张真实Chromium渲染全部无裁切、越界和缺失图片，并逐张视觉检查。Ruff及编译通过。
