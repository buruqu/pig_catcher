2.0.21升级为Battle v13：熠～噜猪近卫真伤改为至少消费8枚指示物，狙击逐发作为独立招式
结算先锋／明日基础加成；达妮娅两种形态重新平衡，加入回合成长型计时溃灭与四项“世界”
招式，并把主招式权重刻度提升到万分位以精确表达0.4444。旧Battle v1–v12场次不被追溯改写。
