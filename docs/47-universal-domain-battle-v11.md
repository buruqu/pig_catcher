# Battle v11：所有战斗猪领域成功统一结算

发布日期：2026-09-01

插件版本：`2.0.19`
协议版本：Schema `60` / Ruleset `58` / Battle `v11` / Manifest `4`

## 通用规则

- 任意战斗猪单方展开领域并通过8:2判定命中，或在双方领域战中获胜，都会同时触发本猪的领域
  功能，并把一份仍有效的领域胜率贡献翻倍。
- 同回合重复展开同一个领域，只选择第一份仍有效领域加倍，不因重复展开获得多份加倍。
- 简易领域免疫、领域战落败、领域战平手，以及数值已经被归零的领域，均不触发该份加倍。
- 撅撅猪同回合开出`荒时之沙`与`乱序数虚时空`的特殊规则不变：只有在真实领域战获胜时，才把
  两个不同领域仍有效的贡献相加后整体翻倍；单方命中仍只加倍一份领域贡献。

## 六只战斗猪的领域功能

| 战斗猪 | 成功后的领域功能 |
| --- | --- |
| 宿傩猪 | 伏魔御厨子的一份仍有效领域胜率翻倍。 |
| 五条猪 | 无量空处的一份仍有效领域胜率翻倍；对方下回合出招数-1。 |
| 撅撅猪 | 荒时之沙令自己下回合+1招、对方下回合-1招；乱序数虚时空自动模仿、自己下回合+1招，并保证下一次加速或时延成功。 |
| 达妮娅猪 | 蚀域令达妮娅切换到幻灭形态，并使自己下回合+1招。 |
| 阿萨姆猪 | 呃呃阿萨姆奶茶使用对方2个随机招式；复制领域不会再次开启领域判定。 |
| 熠～噜猪 | 末日方舟获得“明日”：下回合+1招，且该回合所有招式基础胜率+1。 |

## 版本边界

Battle v11只用于更新后创建的新场次。Battle v1至v10的状态、随机结果、战报和结算口径保持原样。
Schema60只允许Battle v11沿用自然终局3次战利品约束，不修改玩家资产。

## 图片口径

回合结算图会显示领域判定结果、触发的领域效果、被加倍的招式序号和额外胜率。普通领域成功只
显示一份加倍；撅撅猪双领域战胜出时会显示两份领域共同加倍。
