# 2.0.23 达妮娅猪 Battle v15

> 此变更已纳入2.0.25发布批次，运行核验见[本轮发布文档](56-red-packets-and-birthday-20260906.md)。
> 初始开发协议：`2.0.23 / Schema64 / Ruleset62 / Battle v15 / Manifest4`。

## 1. 轮盘变更

达妮娅仍以布景形态入场，蚀域命中或领域战获胜后切换幻灭。两种形态各有5个专属招式，
并共享7个公共招式。Battle v15从新轮盘彻底移除“丸山大姐达妮娅-世界·114514”。

| 世界招式 | 抽取权重 | Battle v15效果 |
| --- | ---: | --- |
| 丸山大姐达妮娅-世界·发龙图 | 1 | 基础胜利权重+10；回合末随机令对方一招的全部自身胜率贡献归零，功能保留 |
| 丸山大姐达妮娅-世界·上班 | 0.5 | 再抽1次；布景令下一次蚀域出现权重+1，幻灭令对方力竭盘永久+0.5 |
| 丸山大姐达妮娅-世界·NMSL | 0.1 | 本回合落败时伤势降低一级；掌握核心保持原结果 |

天衣无缝、未竟的谎言、计时的溃灭、蚀域，以及10个双形态专属招式均保持用户确认的现行数值。

## 2. 精确结算顺序

1. 发龙图只从对方仍有效、具有正数胜率贡献的招式中等权抽取；没有目标时保留自身+10但不失效招式。
2. 多次发龙图逐次从剩余有效招式中抽取，不会对已经归零的同一招重复扣除。
3. 被发龙图命中的招式只清空自己的全部胜率数值；再抽、贷款、领域资格、形态切换与状态效果不回滚。
4. 上班的布景加成使用独立的“仅出现权重”账本；蚀域抽到时清空，但不会进入领域战胜率。
5. NMSL在伤势盘完成抽取后执行：轻伤→无伤、重伤→轻伤、力竭→重伤、掌握核心→掌握核心。
   若复制效果同时拥有时之沙·回溯，先由NMSL降级，再由回溯判断能否撤销降级后的轻伤或重伤。

## 3. 历史兼容与故障修复

Battle v13/v14的轮盘定义被保留为只读历史定义，因此旧战报中的114514名称、真实轮盘和落点仍可
重建。撅撅猪或栖夜流萤抱抱猪曾被114514强制抽到的达妮娅事件，不再进入它们自己的形态轨迹，
避免把“布景/幻灭”解释成“时之沙/虚拟声”或“流萤/萨姆”而触发渲染异常。

新建场次使用Battle v15；旧场次事实不追溯改写。Schema64不增加业务表，只更新自然终局战利品
约束，使Battle v15继续发放3次战利品。

## 4. 验收范围
