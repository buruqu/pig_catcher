# 第二阶段：菜品与活动数值盘点、调整提案

> 2026-08-28；只读基线 `97924b2` / `develop/2.0` / `2.0.0.dev9` / Ruleset 38。
> 本文只记录现状和待确认方案，没有修改代码、目录数值或生产数据，没有上线、发公告或开展全量验收。
> “已做”均指隔离开发线已实现，不代表正式群已生效。涉及术式的部分只记公开玩法，不公开隐藏条件或隐藏成就。

## 1. 结论先行

- 当前高星菜按玩家名称去重，共 **43 道：四星 15、五星 16、六星 12**。普通 QQ 与官方 QQ 四个精确作用域的同名菜效果、参数一致；这不合并玩家数据。
- 已形成普通抓猪、普通做菜、额度、材料补给、巡演、对战、收藏等用途。新五星菜普遍比相应四星菜更强，但旧四星“猪趴柠檬茶”被新四星“猪芙蕾”同方向压过，值得单独确认定位。
- 六星已定数值全部保留。本轮不把“风险分析”当作削弱授权；先确认群体受益范围、榜单口径、奖励回流是否符合预期。
- 最大的规模风险来自按群人数发放的六星宴席、满层额度累计、奖励券回流六星原料、复制猪后续再做菜/售卖，而不是派遣自身无限产币。
- 原有队伍、档期、活动占用、同类排队、事务回执和来源隔离应保留。不要为了控通胀统一削弱所有材料、券或猪币，让新玩法失去入口。

## 2. 当前叠加规则

“独占”是动作结算方式，不等于凡是六星菜就互斥。永久额度、直接到账奖励、全群一次额度等有各自规则。

| 类别 | 当前行为 |
| --- | --- |
| 抓猪概率 P | 一次普通抓猪最多选最早适用的一道概率菜；猪利猪、猪皮奶、虾寿司、猪果冻、黑猪麻汤圆等在同槽排队，不互相乘起来 |
| 抓猪体型 S | 最早适用的一道体型菜；可与 P、复制、收益及一个普通道具并用。体型总偏移限于 −0.50～+0.50 |
| 抓猪复制 D | 珍猪奶茶和猪草莓牛奶同槽排队；可与普通 P/S/收益并用。复制不再给抓猪经验、奖励币、抓取统计或第二次术式处理；复制资产仍可以合法售卖或做菜 |
| 抓猪收益 R | 热猪独立槽，可与普通 P/S/D 并用；固定加币在道具倍率后加，经验倍率按规则结算 |
| 复合巨物 | 黑猪麻汤圆同时占概率和体型位置；不会再消耗另一道体型菜 |
| 普通做菜 C | 猪橘子牛奶、玉子烧、猪籽军舰、提拉米猪、猪咪莓蛋糕同槽排队；只对一至五星原料适用 |
| 六星原料增幅 C6 | 一猪六吃与轮盘“下次六星菜 +30 个百分点”同槽排队；一个普通增幅可与猪饺最多五层、相容道具和永久加成并用，普通层最终六星菜概率上限 50% |
| 做菜份量 V | 猪包蛋独立槽，可与普通 C 和一个相容道具并用；菜与道具份量倍率合计最高 ×2。六星原料不消耗该菜效果 |
| 基础额度 Q | 本轮、今天、滚动七天、永久、自然周分别计时。加的是每个适用时段的额度上限，不是立刻反复清空已抓记录 |
| 专属额外次数 X | 成功抓取才减少次数，不占普通额度，但仍受冷却和处罚硬限额约束 |
| 六星个人独占 | 小马、雾蓝、轮盘等概率抓猪奖励按自己的纯基础分布结算；不叠加等级、饲料、达妮娅或其他概率加成，普通道具和菜保留不消耗。**雾蓝完全纯洗牌**；对战专用战利品不是此类菜品独占 |
| 六星全群独占 | 神龙锅、阿萨姆锅优先于个人独占；同槽依当前有效顺序使用，不相乘，其他被忽略资源保留 |
| 可叠加的全群倍率 | 糖醋排骨、猪鼻蛋包饭是明确例外：可并用普通道具和非六星菜；多个群倍率只取最强，不相乘，额外次数另外结算 |
| 六星做菜独占 | 蛋包饭个人 60% 做菜、彩彩返还保护等先于普通做菜效果；同类排队，其余不适用资源保留。活动期间不允许批量做菜 |
| 即时补给／奖励 | 材料、券、猪币直接到账，不占 P/C 等位置；可累计，券不自动激活。普通多次菜可按顺序参与批量做菜 |
| 群体术式 T | 一个精确群同一时刻一个主动术式；资格可以保存。不是普通概率菜槽，也不是战斗轮盘中的同名招式 |

普通道具本身每种动作只有一个生效位置，同名多份属于按使用顺序排队，不等于同时叠乘。
六星独占与群体术式接管时，相关复制／普通效果按现有兼容条件保留，不能仅按“五星就可叠加”推断。

## 6. 派遣／巡演／对战的当前成本与出口

### 6.1 派遣：时间产材料，不直接产钱

- 队伍 1–3 只，至少一只一至三星，最多一只四至六星；单/双/三猪效率 40%/70%/100%。
- 每 4 小时满编基础 6 份主材料 +2 补给；加成合计最高 30%，即最多 7.8+2.6，零头保存。近郊合并为 8～10.4 补给。
- 四种付费材料路线每 4 小时 20 猪币；近郊免费。可选 4/8/12/24 小时；12 小时有效时长开第二队、72 小时开第三队，多队并行时间取并集。
- 不直接发猪币、经验或普通抓猪价值榜成绩；材料不可出售、转赠或交易。普通材料 3:1 转换是有损转换，不是增产回路。
- 器具成本：地图 3 补给+1 零件；相机 4 补给+2 纤维；罗盘 8 补给+4 零件+1 手记；整理箱 2 补给+1 零件。分别用于材料转向、纪念品去重、固定二选一、有损整理。
- 奇遇基础 10%，连续九次未中第十次中；奇遇会给材料、小纪念或器具，不是每趟固定发一套。

**保留：**低星准入、百分位而非绝对吨位加成、材料来源可追溯、三队及零头机制。
**需确认：**补给菜已成为时间加速入口，是否接受“吃菜绕过等待、但不能伪造自然派遣成就”的定位。

### 6.2 巡演：档期产粉丝与适量猪币

- 初建 2 张档期，每天补 1 张，最多存 7 张；解散不重送初始档期。一张跑三站，完成才给整趟收益。

- 档期券立即补一张，但仍最多 7 张；稳场券最多挽回 3 分，不能保证 SS。

自然档期全部完成时，每周经常性猪币出口为 **1400～3500/人**，初始两张及额外档期券另算；这只是满完成情况下的上下界，不是每周自动发钱。
**保留：**档期上限、一次付费练习、评分分项封顶和不同乐队同一上限。无需把巡演改成材料换大量现金。

菜与一次性成就材料能加速入门，但不应把 +5 当作首周必达的默认目标。
**保留：**先免费 +0 玩起来，重养成为长期追求；本阶段不减五级材料成本。

## 7. 成就和周榜预算

### 7.1 成就：一次性，不按日重发

- 现有 130 项（旧 82 + 新 48），目录条目直接猪币奖励合计 **258900/人**；其中旧条目 190000、新活动 68900。
- 另有成就点 1000 分里程碑一次性 **10000 猪币**，故固定直接猪币总上界 **268900/人**。不把它误算成循环日薪。
- 两个终极收藏条目各 50000，已经包含在上面的 190000 中，不能再加一遍。
- 新 48 项另有基础自选份 372、训练自选份 112、直接组件 294、直接补给 6；含行李券后所有材料上界 808 份。券的路费/强化减免上界共 1320 猪币，属于少支出，不是直接发钱。
- 成就点里程碑另有券、宝箱及外观；常规毕业纪念猪不是普通抓猪，也不另计抓猪周榜。
- 一次性奖励可以触发后续财富类成就，但每条解锁和每个里程碑有领取唯一性；这是有限连锁，不等于无限重复发钱。

**保留：**高难终极奖励、普通成就主要币/券、隐藏条目解锁前遮罩、不增加新的永久概率。
**微调提议：**未来新条目的直接猪币和材料预算先按整组计算，再拆条目，避免每个小成就单看不贵、累计超预算。
