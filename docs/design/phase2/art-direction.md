## 1. 原创方向

用户希望称号具有邦邦活动牌的收藏感。此轮采用横向、主题化、精细装饰的原创猪猪称号牌，
不复制官方角色、队标、截图或某一期活动牌。牌内插画与主体颜色可以丰富，牌外信息仍清爽。

本轮官方资料检索到称号分类和动画纪念称号相关公告：
[2025-09-05官方公告检索入口](https://bang-dream.bushimo.jp/news/20250905/post-343)、
[2026-02-27官方公告检索入口](https://bang-dream.bushimo.jp/news/20260227/post-353)。
两页正文和图片在本次工具打开时均返回404，**没有声称已核验其中原图，也没有将官方素材下载进项目**。
当前样张以用户明确的审美方向、现有猪素材及原创主题为依据；若用户希望贴近某张特定活动牌，可再提供样图定向调整。

## 2. 不同外观不是同一物品

| 层 | 作用 | 制作要求 |
| --- | --- | --- |
| 称号牌 | 展示成就身份 | 原创主题插画／边饰＋程序绘制准确名称；普通、稀有、隐藏已解锁、终极有不同完成度 |
| 周榜名次牌 | 本期赛事荣誉 | 每期独立主题包；第1/2/3和第4–10四种形制；期数、活动名、档位完整可见 |
| 整卡边框 | 结果图的个人外观 | 只在边缘安全区，不能改变素材槽、压缩概率区或错位动画覆盖坐标 |
| 徽章 | 小型可组合纪念 | 原创图标＋名称；不再只靠Unicode符号或颜色区分；有/无/隐藏状态分开 |
| 标签 | 资产与操作事实 | 品质、主题、收藏、锁定、巨物、余次是不同语义；只显示实际生效状态 |

当前概念板里的猪是示意装饰，不是新增可抽猪模板。雨爱只展示已解锁形态，不附隐藏条件。

## 3. 主题样本

| 主题 | 视觉语汇 | 必须保留的信息 |
| --- | --- | --- |
| 雨爱 | 雨蓝、紫色丝带、伞、雨滴、珍珠 | 名称；不写来源机关或解锁动作 |
| 远行家 | 薄荷、地图、罗盘、邮戳、旅行猪 | 称号与旅行身份，不冒充实际领取纪念品 |
| 全场安可 | 玫粉、麦克风、五束灯、音符线 | 名称；不复制官方乐队Logo |
| 我还能再领悟 | 冰蓝、紫色同心纹、手账 | 长标题完整，不把“核心无上限”画成三层封顶 |
| 第1期抓猪冲刺！！！ | 起跑／冲线旗、原创奔跑猪、速度带 | 期数与活动名；四档轮廓不同，4–10共享10牌 |

后续首期包应包含活动头图、1/2/3/10牌、称号牌和整卡赛道边框。下一期重新设计主题，不只改字。

## 4. 生产资产规格候选

- 称号母版建议约1200×360，主体四周保留8%安全区；正式文字不烘焙在插画上，便于纠字与长名称适配。
- 常规称号、各级徽章用静态透明PNG母版、按场景生成有界WebP派生。SVG仅用于代码原生图标与矢量结构，不替代已承诺的主题插画。
- 终极称号和特殊开奖可选择短动效；不是每次背包或抓猪都加大型GIF。已提交结果只回放一次，不在动画中重新抽奖。
- 结果图继续1128px宽；本次样张高约1202–1584px。长效果自然向下延展，密集清单分页；图鉴沿现有全量长图边界另验。
- 称号佩戴槽建议与昵称同行或另占一条固定区；本次使用约312×94的示意。长称号可扩大专栏，不能挤压昵称和核心数值。
- 装饰素材按稳定奖励ID查询；不信任聊天文字中的路径或CSS。隐藏项未解锁时不读取原图。
- 原猪／菜素材始终保留原件、比例与动画；本轮概念图不覆盖旧素材。正式美术包另立版本、来源和哈希清单。

上述尺寸、存储格式和导出数量还需在全量制作前冻结，不是现在已经生成的资产规模。

## 5. 功能卡的信息优先级

1. 当前发生了什么、是否真的结算成功。
2. 物品／猪图、品质、归属、主收益。
3. 本次最终概率及真实来源；这是独立整行，不放进描述尾部。
4. 实际消费和剩余次数，普通额度与专属额度分开。
5. 新获得菜品的效果、未参与效果、到期时刻、下一步操作。
6. 成就装饰、故事、主题标签；装饰不能覆盖前五层。

日常图卡保留白底淡粉，正文深色；派遣薄荷、巡演玫紫、对战蓝／玫红区分语境。
本次演示将说明文字写在图中是为了审批结构，正式游戏会换成真实快照内容，而不是保留“样张玩家”等示例。
