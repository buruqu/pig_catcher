记录日期：2026-08-28。性质：设计确认材料，不是美术完成证明或上线验收报告。

## 1. 本轮边界与真实基线

- 本文只读检查 2.0 开发树；不修改命令、运行代码、数值、配置或数据库。样张与数值提案由同阶段的独立文件承载。
- 本轮只确认代表样张的方向。全量称号、边框、徽章、活动牌、功能图片和统一验收留待后续确认后安排。
- 本份盘点没有启动浏览器、连接 QQ、读取生产库、生成全量图片或部署；同阶段的样张使用独立无头渲染，见主确认稿。
- 基线提交 `97924b2`，插件 `2.0.0.dev9`，Schema 44，Ruleset 38，SDK 2.7.1。
- `asset_library/current/assets.json` 当前含 223 个猪模板、105 个菜模板，合计 328；这包含独立群模板，不等于 328 种不重复内容。
- `pig_catcher/rendering/templates/` 有 32 个 HTML 模板；“有模板”不等于“有专属美术”，也不意味着全部状态已做过本轮验收。
- 现成猪菜原图在 `asset_library/current/media/`；两张 947 原画在 `pig_catcher/rendering/assets/947/`。当前没有在这个渲染素材目录内发现独立称号牌、每期活动牌、手绘徽章、路线背景、舞台背景或战斗招式素材包。

## 2. 最重要的结论

现有功能大多已具有图片输出基础，当前主要缺口是“独立美术身份”，不是重新从零创建所有页面：

1. 称号现在是文字标签，不是用户要求的精美邦邦式活动称号框。
2. 徽章现在主要用 Unicode 符号配小圆圈；不是逐个设计的徽章图。
3. 七类新活动边框已有不同 CSS 描边、邮戳/灯海/彩带表达，但没有精细图案或独立透明装饰层。
4. 周榜已有排行榜和领奖图片，但首期尚无独立设计的 1/2/3/10 牌。领奖卡中的金银铜圆章不能算每期活动牌。
5. 派遣、巡演、对战各有专用模板，但大量子功能共用模块内的通用信息面板；没有逐路线/舞台/招式的专属美术。

因此后续应在保留真实数据、概率、结算和文本可读性的前提下，增加可复用的美术层，不能把新背景盖住现有业务信息。

6. 审计编号/源群路径保留在内部设计记录，不在图面上拼出用户身份或隐藏机制。
