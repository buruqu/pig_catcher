# 三格徽章展示架 · 隔离验收记录

2026-08-29。补齐500成就点里程碑已承诺的真实三槽机制；不是正式上线。

## 玩家规则与入口

- 默认1个徽章位。500成就点里程碑自动发放的`badge-showcase-3`永久权益开放第2、3位；
  只修改显示的点数不能越权开槽。佩戴、卸下均不消耗徽章或展示架。
- `/成就徽章`：图片查看当前槽位和已获得徽章；每页8枚。
- `/成就徽章 查看 2`：翻页。
- `/成就徽章 2 成就自选徽章`：只更改第2位，也接受库存中的徽章ID或对应成就名，ID不区分大小写。
- `/成就徽章 卸下 2`：只清空第2位。
- 旧`/佩戴成就`仍更新该成就提供的称号、边框和默认第1徽章位，不清空未涉及的部位或其他徽章位。
- 旧`/取消佩戴成就`卸下全部外观，包括三个徽章位；奖励库存和开槽资格保留。
- 一枚徽章不能同时占多个位置；移动前须先卸下。已获得的周榜牌、宝箱徽章也可以独立佩戴。
- 查询只列当前群当前玩家已拥有徽章；猜测未获得的隐藏名称只得到通用拒绝，不揭示隐藏条件。
- 成就统计或周榜至少开启一个时可管理已获得外观。纯外观操作不触发成就历史补发、周榜计分、
  猪币、经验或概率变更；已拥有权益不会因关闭成就统计而重新授予或失效。
