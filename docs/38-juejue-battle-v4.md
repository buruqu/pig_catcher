## 1. 入场、形态与即时切盘

- 四个授权素材模板都映射到同一个战斗角色 `juejue`，普通群与两个官方群的素材 ID 不混用。
- 每场入场以对战 seed 等概率选择“时之沙”或“虚拟声”，选择结果写入对战状态，重启后不重抽。
- 两张主招式盘各有 8 格，格子初始出现权重相等；养成只增加数值招式的胜利权重，不提高招式出现率。
- `切换·虚拟声` 会立即改用虚拟声盘并追加 2 抽；`切换·时之沙` 会立即改用时之沙盘并追加 1 抽。
- **切盘在同一回合、同一次 `/出招` 连抽里即时生效。**例如第 2 招抽到切换，第 3 招就从新盘抽，
  不会等到下一回合。分片保存、重启恢复或双方出招先后顺序均不得改变这一结果。

## 2. 时之沙轮盘

| 招式 | 当前实现 |
| --- | --- |
| 时之沙·塑型 | +5；荒时之沙出现权重 +0.1，抽到该领域后清空；下一次加速或时延成功率 +5 个百分点，可累计至 +20，进行一次判定后清空 |
| 时之沙·回溯 | +10；挂起本回合一次回溯。若本回合失败且新抽到轻伤或重伤，撤销本轮新伤势与风险变化；不能挽救力竭，也不清除历史伤势风险 |
| 时之沙·加速 | 进入等权三档盘：1档必成，+15、再抽1次；2档75%，成功+20、再抽2次，失败下回合-2招；3档50%，成功+25、再抽3次，失败下回合-3招 |
| 时之沙·时延 | 进入等权三档盘：1档必成，自己+15、对方本轮-5；2档75%，成功自己+15、对方本轮-10且下回合-1招，失败令对方下回合+1招；3档50%，成功自己+15、对方本轮-15且下回合-2招，失败令对方下回合+2招 |
| 时之沙·沙之形体 | +16；本回合首次生效，对方第一招仍有效的数值贡献减半并向下取整。功能事实不撤销 |
| 时之沙·时空间封印术 | +30 |
| 切换·虚拟声 | 立即切换虚拟声盘，并从新盘追加 2 抽 |
| 领域展开·荒时之沙 | +25；领域命中后自己下回合+1招、对方下回合-1招；领域战基础权重比普通领域少0.5 |

同一回合内，加速与时延各记录成功过的最高档。两者档数之和首次达到 5 时，只进行一次等权判定：
成功发动“相对静止时间·零”，固定 +40，并令对方本回合数值贡献无效；失败后本回合不再复判。
发动成功还会阻止对方本轮招式给撅撅猪留下跨回合负面效果，但不会倒流已经发生的抽数和切盘轨迹。

## 3. 虚拟声轮盘

| 招式 | 当前实现 |
| --- | --- |
| 虚拟声·虚拟之境 | 再抽1次；下一次加速或时延判定必定成功 |
| 虚拟声·未来模拟 | 本回合首次生效，等权随机令对方一招仍有效的数值贡献归零；招式功能保留 |
| 虚拟声·实时演算 | 再抽1次；本回合首次令荒时之沙、乱序数虚时空的出现权重各 +1 |
| 虚拟声·虚拟模仿 | 先等权选择大盘或小盘，再在对应池中等权抽取其他战斗猪的直接有符号数值；不复制再抽、贷款、领域、无下限等功能 |
| 虚拟声·化虚为实 | 本场第 n 次使用时基础数值为 `12 + 5 × (n-1)`，层数不因换形态或换回合清空 |
| 虚拟声·把音乐开大声点！ | 本回合进入不叠层的音乐状态；随后每招固定 +5，固定值不受强化、核心、重伤或贷款倍率影响 |
| 切换·时之沙 | 立即切换时之沙盘并追加1抽；下一次荒时之沙出现权重 +0.5；下一次加速、下一次时延成功率分别 +5 个百分点 |
| 领域展开·乱序数虚时空 | +15；领域命中后自动进行一次虚拟模仿、自己下回合+1招，并保证下一次加速或时延成功；领域战基础权重比普通领域少0.5 |

虚拟模仿的候选池在开战时冻结到对战状态。以后新增战斗猪和数值招式会进入新场次的候选池，
不会改变旧场次；大盘收录绝对值不小于20的数值招式，小盘收录绝对值小于20的数值招式。

## 4. 双领域与通用领域战

- 领域战使用整数放大两倍保存半点，不用浮点随机：普通领域权重3、宿傩4、平手3；撅撅猪每种
  领域基础为2.5。
- 撅撅猪同回合实际抽到两种不同领域时，己方领域战权重为 `3 - 0.5 - 0.5 + 2.5 = 4.5`；
  同一领域重复抽到不重复获得“双领域”加成。
- 双方都开领域时只判一次。明确胜者的一份仍有效领域数值通常翻倍；同回合多次开同一领域不重复翻倍。
- 撅撅猪两种不同领域在真实领域战中获胜时，改为两种领域仍有效的数值相加后再翻倍，并各触发一次领域效果；
  对方本回合数值招式无效。领域战落败或平手时，败方领域数值归零。
- 只有单方开领域时，按命中8、简易领域2判定。单方命中可触发对应普通领域效果，但不发动“双领域获胜”特效。

## 5. 数值成长、无效与回合继承

- 强化等级、掌握核心、重伤惩罚只结算一次，适用于普通数值招式、成功的加速/时延、领域及模仿数值；
  纯功能招式不因升级凭空获得数值。音乐固定 +5、相对静止固定 +40 不吃成长。
- 功能招式后来被数值免疫时，只撤销该招的数值贡献，不倒流已经保存的追加抽取、形态切换等事实。
- 同一数值不能被无下限、未来模拟、沙之形体、相对静止或领域落败重复扣除；结算图保留每个原因与实际扣值。
- 本回合用完整最终权重判胜负。进入下一回合时，每个历史回合的净新增分别保留50%，向上取整；基础5不衰减。
- 所有轮盘使用对战 seed、规则版本、回合、阵营和招式序号组成确定性命名空间；重复消息、失败重试和重启不重抽。
