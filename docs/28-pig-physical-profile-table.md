## 测量口径

- 数值是游戏缩尺，不是对图片进行现实测量。普通乐器/背景不计入猪的身体；
  谱面、多只叠放、建筑或器物化的主体以完整组合为准。
- mini/standard/giant是物种形象档案；实例的迷你/巨物、轻重品质仍按原百分位规则判定，
  不因新范围修改而回算历史属性或成就。
- 大但轻与大而重分别设定：例如彩虹云猪长90–360cm，重0.8–35kg；星体采用最大100t缩尺。
- 以下是后续新生成的上下限。既有猪的体长、重量、百分位、价值和编号保持原值。
- 数据库存cm/kg；前端重量达到1000kg换算成t、体长达到1000cm换算成m，排序仍用原值。
- 展示标签不参与概率、食谱、派遣特长或巡演身份；全部223个模板另有明确旅行特长。
- 猪猪？本轮按用户文件夹改为四星，保留稳定模板ID；旧实例仍不回算。
