## 1. 招式变更

| 招式 | Battle v14效果 | 未改变部分 |
| --- | --- | --- |
| 时之沙·塑型 | 胜利权重+15 | 荒时之沙出现权重+0.1；下一次加速或时延成功率+5个百分点，最多累计+20 |
| 时之沙·加速 | 子盘成功后自己下回合出招数+1 | 三档数值、当回合追加抽取及失败欠招保持原值 |
| 时之沙·时延 | 子盘成功后自己下回合出招数+1 | 三档数值、对手减权／欠招及失败给对手加招保持原值 |
| 虚拟声·未来模拟 | 胜利权重+15 | 每次抽中仍独立随机令对方一招有效数值归零，功能保留 |
| 虚拟声·实时演算 | 首次+5并再抽1次；同回合重复抽中改为+10并再抽2次 | 两种领域出现权重各+1只在首次建立，不叠层 |
| 虚拟声·把音乐开大声点！ | 首次开启音乐状态并再抽1次 | 随后每招固定+5；重复抽中不叠层并再抽2次 |
| 领域展开·乱序数虚时空 | 胜利权重+20 | 领域成功后的自动模仿、下回合+1招、保证下一次子盘成功及通用领域翻倍均不变 |

招式的“胜利权重”和主盘“抽取权重”仍是两套独立数值；本次没有提高这些招式被抽中的概率。
培养等级继续只增加带数值招式的胜利权重，不改变招式抽取概率。

## 2. 分支与叠加

- 每次加速或时延成功各自提供一次下回合+1招；同回合多次成功可以累加。
- 加速或时延失败不提供这次加招，原有失败惩罚照常结算；回溯仍只处理既定的加速失败欠招。
- 实时演算第二次及以后每次都按+10、再抽2次；领域出现权重仍只有首次的一层。
- 音乐第一次按“建状态+再抽1次”，第二次及以后按“不叠状态+再抽2次”。
- 领域成功时沿用Battle v11统一规则：单方命中或领域战获胜会触发领域功能，并翻倍一份仍有效领域胜率。

## 3. 数据与兼容

Schema63不新增业务表，只重建`battle_loot_total_insert`约束，使Battle v14自然终局继续使用3次战利品。
迁移不改玩家、猪猪、材料、养成等级、历史场次或既有战利品。规则事件新增“实时演算重复”和
“子盘成功加招”事实，图片可明确展示首次／重复以及成功／失败结果。
