# PiG Dream! 猪猪巡演：自由乐队与角色特色设计

> 设计版本：tour-design-r1。整理日期：2026-08-27。状态：完整玩法设计，尚未实现。
>
> 保留前期的自由混团、三站演出、全乐队角色招牌、关系合奏和轻养成，不并入派遣挂机。
> 数值是设计取值，不代表已经上线；角色与猪名按当前正式清单核对，演出技能为本插件原创。
>
> 总入口见 [三大机制总方案](21-v2-three-systems-design-summary.md)；材料来源见
> [猪猪远行社](19-pig-dispatch-system-design.md)。本轮不制作图像资产、不更改现有立绘或角色定义。

## 1. 玩法目标

让玩家按喜好组建猪猪乐队、排练歌曲、安排三站巡演，收集乐队故事和舞台外观。
不是音游操作测试，不要求上传音乐或依靠真实群友点赞；演出结果由公开规则计算，不交给 LLM。
不会吞猪、改变猪的星级与原价值，也不提供永久抓猪／做菜概率提升。

派遣给低星猪旅行和材料，巡演给音乐角色自己的舞台。派遣的“旧舞台仓库”只是收集器材，
不替代本系统的歌曲、观众、角色互动、粉丝和舞台评分。

## 2. 自由组团

- 每名玩家一个主乐队，可设置名字、简介、主题色、队徽、队长和主唱／中心位，保存三套阵容。
- 每套三至五只具有音乐角色身份的猪；原团、混团都可以，同样能达到评分上限。
- 至少覆盖主旋律、节奏与伴奏／低音三个职能；允许主唱兼吉他、贝斯兼主唱、双鼓、双吉他、
  DJ 和小提琴等组合，不强制五个固定职业槽，更不强制拥有一只键盘猪。
- 评分看覆盖与编排质量，不按人数直接相乘；三只与五只都能拿满分，五只主要提供更多选择。
- 同角色不同猪或形态可组成趣味阵容，但同一角色的个人招牌／关系加成不重复触发。
  初华戴帽立绘不算第二位成员；美咲与米歇尔、黄瓜与墨提斯使用巡演独立的身份别名映射。
- 别名映射只影响巡演组合，不修改现有图鉴槽位、收藏分母或成就已经冻结的集合。
- 切换阵容、改名、暂时换人不会清空粉丝、歌曲熟练或老成员默契；同一只实例不能占两个台上槽位。

例如“天才猪＋薯条猪＋巴巴猪＋魔王猪＋LAYER猪”是双吉他、双鼓、贝斯兼主唱的合法混团，
不是因为缺传统键盘位而被扣成残缺队伍。原团有专属主题和纪念物，不得到压倒混团的固定乘数。

## 3. 一趟巡演怎么进行

一趟三个舞台，每站选择开场／中段／终曲三首原创歌曲卡，配合观众偏好、舞台主题和个人招牌。
歌曲以风格与编排标签表达，不分发版权音频，不把邦邦官方谱面复制成小游戏。

流程为：编队 → 选择三站路线 → 安排曲目与招牌 → 看成本及预估 → 确认 → 逐站演出 → 总结。

- 可以逐站调整下一站，也可以一键演完整趟；两者采用相同评分、随机快照和奖励规则。
- 演出即时结算，不再等待 4／8／24 小时；暂停下一站不等于演出失败，不要求三分钟内点按钮。
- 档期归玩家，不归乐队名字：初次开团一次性给两张，之后北京时间每天补一张，最多存七张。
  一张跑三站；同一玩家删团、改名、换阵容都不能重新领开团档期。
- 免费排练只展示确定性预估和编排建议，不随机发材料、经验、粉丝或猪币，不能反复预演刷好结果。
- 已确认的站点随机结果与费用不可回滚重抽；服务器／图片异常从已提交回执继续。
- 不在群里自动发布九条歌曲消息。单站可一张卡，一键全程只生成合并总结及需要的分页。

## 4. 观众、场地和评分

| 场地 | 特色 | 解锁方向 |
| --- | --- | --- |
| 街头舞台 | 亲近、轻松，新团也能完整演出 | 初始开放 |
| 校园祭 | 热闹、互动、鼓点 | 建议累计 200 粉丝 |
| Livehouse | 技术、风格连续性 | 建议累计 1,000 粉丝 |
| 城市剧场 | 叙事、转场与舞台美术 | 建议累计 3,000 粉丝 |
| 梦想巨蛋 | 长线乐队目标，综合编排 | 建议累计 8,000 粉丝 |

观众是规则生成的虚拟观众，不是 QQ 群在线人数；应援与联演不要求群友刷消息。
场地解锁看乐队经营，不看是否集齐某支官方乐队。档期包含标准场地使用，不额外强制收高额场租。

| 评分组成 | 满分 |
| --- | ---: |
| 演出能力与职能编排 | 35 |
| 成员默契与歌曲熟练 | 25 |
| 曲目顺序与观众偏好 | 25 |
| 舞台主题与角色高光 | 10 |
| 器材 | 5 |
| 总计 | 100 |

结果可有最多 ±3 分的轻微现场变化，最终夹到 0–100；不得随机让投入充分的乐队损失猪猪或清空养成。
评级初稿为 C＜50、B≥50、A≥65、S≥80、SS≥92。开发时需用不同阵容离线模拟校准，
确保混团、三人团、新团均有成长路径，不能只有同原团五星满级才拿 S。

装备最多贡献五分；招牌和组合效果只作用于各自评分项或体验，不能突破对应分项上限，
不能五人每人再挂一个全队百分比加成。

## 5. 三条轻养成

1. 单猪演出训练：最高十级，绑定实例，正式演出自然成长；可用舞台材料补充练习。
2. 成员与本团默契：成员加入后积累，换回老成员保留，不因不登录衰减。
3. 乐队与歌曲熟练：同一首曲目演出形成熟练，改团名不重置；练熟也不代替合理曲序。

不做每日饲养、掉级、养成失败、同名猪合成或必须吞掉六星猪的突破。
分支采用同层互斥的风格选择，可以在预览明确代价后改分支，不让玩家因第一次点错永久报废。

训练经济初稿：每完成一站成员得 20 演出经验；第 k 级需新增 40×k 经验，升十级累计 2,200。
可选练习每只每天一次，消耗舞台组件 5、补给 3、猪币 50，获得 50 经验；满级不能继续扣费。
仅自然演出约 37 趟三站巡演可满训练，不强迫先派遣才能上台。满经验后的剩余当次经验
保留为统计而不跨系统兑换；它不是既有抓猪玩家等级经验。

其他成员仍参与基础演奏。相同角色不同形态不能一站占两个高光位或重复提供合奏条件。

### 其他定制与客串

- 绿茶猪对应清单中的薇欧拉，以花与“小小幸福”作为客串主题；不擅自认定她是现有五人团
  的某个器乐席位。适用范围按角色定义明确登记。
- 彩彩修车猪是用户定制的彩相关梗形态，可共享丸山彩巡演身份；“修车”不写成官方职业设定。
- 软糯丰川祥猪等已经确认的角色定制形态可共用对应身份，数值不因六星额外翻倍。
- 渚泪滴这类谱面梗更适合曲目／舞台客串，不硬塞成一名人物。其他未确认角色的定制猪不猜映射。

## 8. 收益、器材与联演

- 粉丝是经营进度，不是可转售货币。每趟建议 C／B／A／S／SS 得 40／60／80／100／120 粉丝。
- 猪币建议每完整三站固定结算 200／260／340／420／500；不是每首歌都发一遍。
  不含玩家自愿购买练习或消耗器具的支出；初次通关奖励另列为一次性账本。
- 主要收藏为票根、城市海报、成员高光照片、主题服装、队徽、称号、舞台外观和演出历史。
  已获得历史和玩家成就不随猪猪交易送给新主人。
- 器材最多五评分点，可用舞台组件、零件、纤维升级；不改变抓猪概率、战斗招式或原猪价值。
- 每站至多一件功能器具，例如备用线缆处理一次设备小状况、提示卡帮助一个已知转场、
  留声机保存收藏高光；礼花主要是视觉效果。使用在结果确定前确认，不看完分数再补吃道具。
- 可做双乐队联演：双方明确接受，各消耗自己的档期、各结算一份正常奖励，生成共同海报。
  不借用对方猪的所有权，不因两个人互刷应援把一次档期变成两次收益。

练习、器具、器材和主题布置的具体评分系数需在巡演开发轮次做离线平衡，不能提前把材料
卖成无实际功能的商品；本轮确定材料来源、养成上限和收益边界，不宣称已经跑过阵容模拟。

## 10. 架构、素材与后续验收

成员身份别名、职能、招牌、组合、曲目、场地、观众、评分项和奖品各有独立版本化定义。
同一身份可有不同形态与卡面，但不能靠改正式 collection 数据实现巡演去重。

不直接从网页抓整套官方素材打包，也不把本轮设计记录说成已经完成全部绘图。
