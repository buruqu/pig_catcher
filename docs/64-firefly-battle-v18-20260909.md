# 2.0.33 流萤 / 萨姆战斗盘改版

协议：Schema71 / Ruleset72 / Battle18 / Manifest4。依据用户提供的《流萤战斗猪改版设计.docx》，只修改战斗规则和展示；四个既有授权范围共享同一角色定义，玩家数据各自隔离。

## 被动与形态

初始为流萤。使用流萤技能获得1层燃芯（技能中的同名“燃芯+1”是对被动的说明，不重复计入），上限3层。每层使萨姆技能胜率+5、抽取权重+0.1。天火轰击额外获得1层燃芯，先获得再计算本招加成。点燃星海描述中的同名燃芯加成沿用现版，只计算一次；发动后清空燃芯。

溃败上限3层，每层使萨姆技能胜率额外+5；底火斩击自身另有每层+5，与被动叠加。1/2/3层使当前回合力竭格权重分别增加0.08/0.18/0.35。用户明确确认半效残梦的溃败也减半，允许0.5层；半层力竭增量按相邻整层线性插值：0.5/1.5/2.5层为0.04/0.13/0.265。所有中间值使用精确有理数，跨重启不取整；条件“已有2层”“已有3层”按真实层数判断。同一回合待结算层数也受3层上限约束。

流萤抽到萨姆技能立即变身，本招出现权重-0.1；萨姆持续2回合，包含进入的当前回合。萨姆抽到流萤技能触发残梦，不退出形态、不获得燃芯。领域技在流萤形态发动时沿用“不强制变身”，结算时若已是萨姆则延长1回合；无论形态均获得下一回合的出招和溃败效果。

## 残梦回声

- 赤染之茧：自身+8、对手-8、溃败+1。
- 梦应归于何处：溃败+1、对手-10、自身当前力竭-0.15；对手发动前至少2层溃败时，其当前力竭再+0.15。
- 飞萤之火：仅再抽1个；萨姆技额外+12；流萤技执行半效残梦，数值、力竭增减、溃败层数均减半，不获得燃芯。若仍抽到飞萤之火，继续按单候选链执行；整数抽取次数不减成半次。
- 沉睡在静默的星河：自身当前力竭-0.15、对手-8、溃败+1；对手发动前至少2层溃败时，其当前力竭再+0.1。

## 与共通规则衔接

“胜率”沿用游戏的胜利权重点数；招式出现权重、领域战权重、伤势格权重是独立量。常规减权继续受本回合起始值下限约束。领域命中/获胜保留全角色统一的有效领域自身增益翻倍；对手减权不翻倍，焦土陨击+12不重复翻倍。没有领域命中时不追加焦土陨击，但领域正文的溃败和下一回合效果仍生效。

“本回合已有增益 / 对手高于我方”使用双方招式完成后、定向减权前的同一快照，真实消息先后不影响结果。星河按有效正向招式收益减半，包括领域翻倍及领域追加收益，负收益和回合起始值不受影响；重复星河按每次50%连续折算。已有数值清零、防御和定向保护继续先行处理。星河残梦不包含正常形态的50%压制。

飞萤之火沿用固定评分自动选择，不新增交互等待。候选、随机数、选定项和追加效果都冻结在原战斗状态；选择的萨姆技同时享有正常直接变身加层和选择额外加层。当前回合力竭增减全部写入当前回合，不污染永久力竭字段；下一回合溃败在本轮伤势判定结束、进入新回合时增加。
