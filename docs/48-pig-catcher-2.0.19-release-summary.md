# 抓猪 2.0.19 正式发布总结

## 发布信息

- 正式版本：`2.0.19`
- 数据协议：`Schema60`
- 数值协议：`Ruleset58`
- 战斗协议：`Battle v11`
- 素材协议：`Manifest4`
- 兼容环境：Python `>=3.12`、`maibot-plugin-sdk >=2.7.0,<3.0.0`
- 仓库：<https://github.com/buruqu/pig_catcher>

抓猪 2.0 将原有的抓猪、做菜、背包、图鉴、商城、赠送和交易扩展为一套完整的群聊收集游戏。
2026-09-01 已在四个既有 QQ／QQ 官方会话范围完成正式切换；本次 GitHub 发布把正式源码、迁移、
文档、测试、渲染模板和授权素材统一整理到同一个可追溯版本。

## 2.0 主要内容

### 收集、做菜与经济

- 六档猪猪与美食、328 项正式模板、223 只猪和 105 道美食；每个已授权群可见 187 只猪和 69 道美食。
- 全猪展示标签与逐图设定的体长、体重范围，支持吨级巨物、迷你个体、每日巨物榜和群纪录。
- 第九期新猪、新菜、专属原料菜、编号生命周期、收藏保护、名称直选、批量做菜与按菜名批量售卖。
- 十层猪饲料／厨具成长、独立派遣／巡演／对战商城、5% 交易税和每日赠送／收赠次数限制。
- 同名菜快捷食用、最后一份确认、道具批量使用、效果余次与最终概率图片展示。

### 成就与每周活动

- 130 项 PiG Dream! 成就，包含公开成长目标、长期终极目标和只在解锁后揭示的隐藏彩蛋。
- 奖励不只包含猪币，还包括材料、专用券、称号、边框、徽章和展示架权益。
- 可扩展周冲榜支持独立活动规则、分页榜单、确定性结算，以及每期单独设计的邦邦式活动牌。
- 默认一格徽章展示位；达到成就点里程碑后开放三格展示，不消耗已拥有外观。

### 猪猪派遣

- 支持手动组队、路线选择、器具、途中奇遇、召回、材料背包和派遣游记。
- `/猪猪派遣 自动 <路线> [时长]` 会按路线收益与当前空闲猪自动选出最佳合法队伍，一次确认后出发。
- 派遣为低星猪提供长期用途，并为战斗养成、器具制作和其他玩法提供材料来源。

### 猪猪巡演

- 支持同乐队一键配队、自由混团、自定义猪猪乐队、三站路线、联演、练习与巡演游记。
- `/猪猪巡演 自动 <乐队名>` 会从同团空闲猪中自动完成合法配队，并选择当前已解锁的推荐路线。
- 乐队保护、活动占用和跨重启恢复均独立保存，收藏猪可参演但不会被其他流程误消费。

### 猪猪对战

- 宿傩猪、五条猪、撅撅猪、达妮娅猪、阿萨姆猪和熠～噜猪拥有独立战斗盘与养成路线。
- 双方在线接受后逐回合抽取出招数与招式；结算图完整展示两边招式、胜率构成、伤势盘和领域结果。
- Battle v11 统一所有战斗猪的领域成功规则：单方领域命中或领域战获胜都会触发领域效果，并翻倍
  一份仍有效领域胜率贡献；旧 Battle v1–v10 场次按历史规则保留。
- 五级强化只提高数值招式收益，不改变招式出现概率；自然终局战利品、超时、认输、每日次数和同群
  单场并发均有明确约束与可恢复记录。

### 图片与交互

- 85 个显式斜杠命令和 1 个管理首页，不监听普通聊天、不调用 LLM。
- `/抓猪帮助` 为精简入口，派遣、巡演、对战、成就、周榜、商城、批量和叠加规则按专题展开。
- 抓猪、做菜、成就、派遣、巡演、对战、商城和群事件均优先生成白色／淡粉红主题图片；图片失败时
  返回包含完整业务结果的文字，不回滚已经提交的事务。
- 83 项独立外观美术包含称号、整卡边框、徽章、名次牌和展示架；首期周榜拥有独立 1／2／3／10 牌。

## 数据与发布安全

- SQLite 从旧版本逐级迁移至 Schema60；启用外键、WAL、显式事务、幂等业务回执和结构指纹检查。
- 猪币、资产、赠送、交易、做菜、奖励和对战结算均以数据库事务提交；重复消息不会重复发奖。
- QQ 与 QQ 官方会话使用稳定作用域隔离；显示昵称只用于渲染，底层身份仍使用平台稳定 ID。
- 正式发布包不包含数据库、运行日志、缓存、备份、临时素材、密钥文件或一次性管理开关。
- 图片素材由 Git LFS 管理；克隆仓库后必须执行 `git lfs pull`，否则只会得到指针文件。

## 安装与升级

1. 停止 MaiBot，并备份原插件目录、`config.toml` 和运行数据库。
2. 克隆本仓库或下载对应版本，将插件放到 MaiBot 的 `plugins/pig_catcher`。
3. 在仓库中执行 `git lfs pull`，确认 `asset_library/current/` 与渲染美术素材完整。
4. 按需合并旧配置；不要把仓库示例配置当作机器人密钥存放位置。
5. 启动 MaiBot，确认日志显示 `local.pig-catcher v2.0.19`、Schema60，并执行 `/抓猪帮助`。
6. QQ 官方机器人接入见 README 的“QQ 官方机器人安装教程”；网关适配器与抓猪插件分别安装和升级。

升级生产数据时必须让代码与数据库版本成对备份、成对回滚；不要让旧代码直接读取已经迁移到
Schema60 的数据库。
