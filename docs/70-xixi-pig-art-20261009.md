# 西西猪与配套美食美术稿（2026-10-09）

本轮交付六星猪「西西猪」、配套六星美食「西西昭日星酪」，以及三道特殊六星奖励菜「水蜜桃」「粑粑柑」「达妮娅的生日蛋糕」。图片、正式模板和用户指定效果已随2.0.35正式发布；规则与验收见[效果文档](71-xixi-feast-20261009.md)。运行端已更新，见[正式发布记录](74-pig-catcher-2.0.35-release-summary.md)。

## 参考与修改

- 画风参考素材库的达妮娅猪、达妮娅泡泡云冻：圆团动物比例、短蹄、简洁猪脸、柔和粉彩、纸张颗粒、白色聚光灯与淡紫背景。
- 角色身份与性格参考[鸣潮官方角色介绍](https://wutheringwaves.kurogames.com/en/main/news/detail/4447)：星炬学院学生、罗伊符文共鸣者，努力回应大家的期待并成为合格昭日者。
- 造型参考[西格莉卡官方档案](https://wutheringwaves.kurogames.com/en/main/news/detail/4393)、带鸣潮标识的[角色宣传图](https://pbs.twimg.com/media/HDTlWY0bcAAPoII.jpg?name=orig)，以及用户提供的笑脸参考图。研究参考文件保存在本地忽略的 artifacts 目录。
- 首稿缺少标志性头饰，且橙色卷发与太阳发夹过于泛化，已弃用。第二稿保留白色头带、两侧折翼饰件、紫白垂带、额前小珠饰、翘起的前发和分段编辫，并采用圆脸笑眼。主体保持猪的鼻子、耳朵、卷尾与四条短腿。
- 水蜜桃与粑粑柑按用户补充的两张参考图改为角色水果团子：水蜜桃使用粉蓝卷发、紫色大眼、蓝宝石扇形发饰和委屈张嘴表情；粑粑柑使用橙色编辫、白色折翼头饰、含泪绿眼与鼓脸小拳头。保留参考图的角色特征，用素材库的粉彩手绘表现，移除货架、价格、字幕和视频标记。
- 生日蛋糕参考[游戏任务物品图标](https://wuthering.gg/images/items/T_IconTask_Task_215_UI.png)的双层奶油、橘片、草莓和蜡烛轮廓，加入小猪鼻奶油装饰。选定修正题字后的版本，名称完整写作「达妮娅的生日蛋糕」。
