# 需求来源与追溯矩阵

## 1. 输入来源

本轮设计基于：

- 用户提供的《抓猪插件.txt》初步构想。
- 四张同类收集插件截图，仅用于分析信息层级和展示场景。
- 本机 MaiBot `1.0.12`、`maibot-plugin-sdk 2.7.x` 和现有插件开发规范。

截图中的水母题材、深蓝背景、素材、文案、具体卡片与排行布局均不属于本项目需求，也不进入后续资产。

## 4. 参考图分析结论

可借鉴的信息组织：

- 单次详情突出主体素材和三个核心属性。
- 背包需要进度、筛选、数量和稳定网格。
- 图鉴按品质拆分，并明确未收集状态。
- 排行榜在群聊中优先展示前十和关键统计。

必须形成差异的部分：

- 深蓝改为白色、淡粉结构和多品质点缀色。
- 水母图标和题材全部替换为用户后续提供的猪与美食素材。
- 不沿用其外层面板、内层卡片、胶囊筛选器和排行行样式。
- 单次结果改用“称重证书”，商城与交易改用“粉色票据”，图鉴改用“收藏索引册”。
- 不复制参考图中的任何文字、数值、名称和装饰。

## 6. 当前缺口

- 正式素材、描述、群授权和合理属性范围已在 2B 接入；字体和独立品牌图标尚未交付。
- Manifest 当前暂用名称“抓猪插件”、作者 `buruqu`、MIT 和预留仓库地址；远程仓库尚未创建或推送，发布前仍可调整。
- 正式高星美食效果已经接入并持久化；未来新增素材仍需逐项声明效果 ID、参数、品质和描述。
- 抓猪、收藏、做菜、经济、赠送、两阶段交易、展示位和七类排行榜均已完成。
- 特殊体型当前为首批显式配置：特小猪 `4–16 cm / 0.35–6 kg`，大象 `120–260 cm / 350–1800 kg`；后续素材仍可继续补充独立体型档案。
- 待确认默认项集中列在 `docs/07-roadmap-and-acceptance.md` 第 5 节。

这些缺口不影响第五轮社交与排行玩法。
