# dev13 商城重平衡与独立器具商城验收

验收日期：2026-08-29。目标版本：`2.0.0.dev13 / Schema48 / Ruleset41 / Manifest4`。
本报告只证明隔离开发线；没有修改正式1.x代码或数据库，没有启动MaiBot、连接QQ、发公告或推送远端。

## 已实现

- 主商城16件商品采用本轮确认价格；幸运猪哨、超级幸运猪哨、星辉探猪镜的六档基准分别为
  `35/27/16/12/7/3`、`29/23/15/15/12/6`、`0/0/47/30/18/5`。
- 猪饲料与厨具从5层平滑扩展为10层。饲料每层对4/5/6星相对权重增加
  `1%/2%/3%`，厨具每层增加高档菜相对权重`2%`；Lv.10与旧Lv.5完全等效。
- Schema47把旧升级等级精确映射为`旧等级×2`，保留时间戳，不追收差价，也不伪造购买流水。
- `/猪猪商城 派遣|巡演|对战`分别展示4/4/3件既有器具，不混入主商城“全部”。
  `/购买`直接写入原派遣、巡演、对战器具库存；原材料制作、携带、消耗、退回和活动规则不变。
- Schema48新增不可变功能器具购买账本。扣币、发货、数量账和命令回执在同一事务中提交；
  同消息重放不重复扣款或发货，余额不足与中途失败完整回滚。
- 商城帮助、命令白名单、纯文字回退和图片页面均同步；关闭对应玩法开关时，其分商城和购买入口一同拒绝。
